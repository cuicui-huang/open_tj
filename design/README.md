# 设计参考（Alma）

这些图由 MyGo 的 headless 渲染器（`ui.NewTester` + `tt.Image()`）生成，
是**真实像素**，不是手绘稿。

| 文件 | 内容 |
| --- | --- |
| `compact-overview.png` | 概览 · 已连接（940×700，含一条警告一条错误探针） |
| `compact-narrow.png` | 概览 · 默认窗口 860×600，全部内容无需滚动 |
| `compact-idle.png` | 概览 · 未连接（连通性与流量都是单行空状态） |
| `compact-settings.png` | 设置页（三个分组） |

## 间距基准

| 位置 | 值 |
| --- | --- |
| 内容区外边距 | `18, 20` |
| 区块之间 | `11`（设置页分组之间 `16`） |
| 卡片内边距 | `13, 14`（hero `14, 16`） |
| 卡片圆角 | `12`（hero 与流量卡 `14`） |
| 列表行高 | `30`（probe 行、会话行、设置行） |
| 侧栏项高 | `30`，侧栏宽 `196` |
| 状态环 | `40` |
| 速率数字/单位 | `24` / `12`，`ui.Baseline` 对齐 |

## 原则

- 未连接时不渲染空图表：连通性和流量都收成一行说明，代替两张只有 `0` 的卡片。
- 分组标题紧贴它所属的卡片（组内 5），组与组之间留 16，归属一眼能看清。
- 数字与单位共用基线，不靠 `Margin` 硬凑。
