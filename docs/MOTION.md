# 动效规范

本文件说明 Open TJ 桌面端的动画：为什么动、动多少、什么时候不动。
实现在 `apps/desktop/internal/app/motion.go`，所有时长与弹簧都集中在那里。

## 一条原则

**动画解释状态变化，不做表演。**

满足这条才加：它让用户看懂「发生了什么」或「东西从哪来」。
不满足就不加，哪怕看起来更花哨。

具体三条红线：

1. **静止时必须静止。** 没有任何东西在动时，窗口不得请求下一帧。
   `TestMotionIsIdleAtRest` 守着这条。
2. **循环动画只允许一处。** 只有「已连接」的呼吸圆点循环，因为它在表达
   「隧道还活着」这个持续状态。其余一律一次性。
   `TestOnlyLiveDotLoops` 守着这条。
3. **每个动画必须收敛。** 永远播不完的过渡和卡死没有区别。
   `TestPageChangeAnimatesThenSettles` 守着这条。

## 清单

| 位置 | 动作 | 时长 / 曲线 | 为什么 |
| --- | --- | --- | --- |
| 页面切换 | 上浮 10px + 淡入 | 220ms EaseOut | 让「去了另一页」有方向感，而不是换了一张图 |
| 状态环 | 缩放 0.96 → 1.04 | 320ms 弹簧，bounce 0.22 | 点击后立刻有反馈；轻微过冲表示「收到了」 |
| 状态文字 | 字形变形 | 默认弹簧 | `未连接` → `已连接` 是同一个位置换了内容 |
| 速率数字 | 数字滚动 | 260ms 弹簧 | 每秒变一次，滚动比替换更像仪表，不像闪烁 |
| 探针行 | 逐行上浮 6px + 淡入，每行延迟 28ms | 200ms 弹簧 | 检测结果「依次到达」，而不是整块弹出 |
| 探针错误说明 | 折叠展开 | 200ms EaseOut | 行变高而不是跳变，说明是新增信息不是替换 |
| 侧栏选中条 | 高度 0 → 15px | 160ms EaseOut | 选中是「长出来」的，比颜色突变更容易被察觉 |
| 在线圆点 | 缩放 1.0 ↔ 1.16 循环 | 1800ms 往复 | 唯一循环项：表示隧道仍在 |
| 按钮悬停 / 按下 | 底色过渡 + 缩放 0.97 | 120ms / 弹簧 | 已有的基础反馈 |

## 两个踩过的坑

**方向符号是反直觉的。** `ui.Motion{Y: 8}` 让元素从**上方**落下（起始 y=0，目标 y=8）。
想要「上浮」必须写负数。我是先渲染中间帧量出来的，不是查文档猜的。
`TestPageEnterRises` 断言 `pageEnter.Y < 0`。

**`AnimatePose` 不是循环动画。** 它把值弹到一个新目标就停；目标不变就永远不动。
做循环必须用 `Keyframes` + `RepeatForever`。我第一版用 `AnimatePose` 配手算正弦，
结果圆点只跳一下就不动了。

## 无障碍

MyGo 自带 `Preferences.ReduceMotion`：用户开启「减弱动态效果」后，
位移与缩放会直接到位，只保留淡入淡出，颜色仍平滑变化。
应用侧不需要额外判断——除了循环动画，`Keyframes` 也会在减弱动态时停。

## 侧栏的层次

侧栏不是一条紧凑列表，是四段用分隔线隔开的信息：

```
品牌（交通灯下方）
──────────────
状态条  · 只在有会话时出现，只显示时长
──────────────
导航     · 行高 32，间距 2，快捷键悬停才出现
……（弹性空白）
──────────────
页脚     · 网关 + 认证方式，一行
```

两条经验：

**重复是拥挤的来源。** 状态条原本也写「未连接 / 同济大学校园网」，而右边的
主卡片大字写着同样的话。删掉重复后，侧栏立刻松了——不需要缩小任何尺寸。

**常驻的辅助信息会吃掉主信息的空间。** 快捷键提示原本占满一列，把标签挤在
最左边。改成悬停淡入后，标签回到自然的左对齐位置，四行看起来也不再密。

分隔线用 `p.divider`（14% 不透明度），比卡片内的 `p.hairline`（10%）实一档：
侧栏底色和卡片底色接近，太淡的线等于没有，而有断点的侧栏才读得出结构。

## 尺寸

应用只有四个短页面，窗口按它们定，不按仪表盘定：

| | 值 | 依据 |
| --- | --- | --- |
| 默认窗口 | 660×470 | 概览在信息最满时（4 条探针 + 会话信息）无需滚动 |
| 最小窗口 | 580×400 | 设置页开始需要滚动，这是它的自然下限 |
| 侧栏 | 176 | 品牌 + 四项导航 + 页脚，留白均匀 |

`MaxWidth` 必须小于「最小窗口宽 − 侧栏 − 内边距」，否则在最小尺寸下内容会被
挤到一侧：580 − 176 − 32 = 372，所以内容上限取 380/430 而不是 460/500。
